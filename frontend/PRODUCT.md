# UNMET frontend

UNMET is a market for unmet AI-agent demand. Supporters commit test USD₮0 to capabilities; builders submit services for weighted approval or rejection. Only explicit approver funds settle. Other eligible commitments remain refundable.

This interface serves demand funders and builders comparing capability, escrow, calls, price and review state. Preserve the existing wallet, receipt, readback and action rules. This redesign changes presentation only; it does not authorize deployment or transactions.
