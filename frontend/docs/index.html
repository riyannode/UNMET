UNMET API documentation

UNMET exposes public chain-derived demands and a separate paid endpoint for ranked demand intelligence.

Free demand data

GET /v1/demands returns up to 50 public demands, with no payment. Its JSON contains chain metadata and legacy public demand fields; it does not include the paid ranking analysis.

Paid demand intelligence

POST /v1/opportunities accepts a JSON filter object and returns ranked opportunities with score breakdowns, economic signals, and deterministic cautions.

curl -i "$API_ORIGIN/v1/opportunities" \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  --data '{}'

An unpaid request returns HTTP 402 and an x402 challenge in PAYMENT-REQUIRED. Use any x402 v2-compatible client that supports the offered EIP-3009 payment method on the configured chain and token to follow the challenge, then replay the same request with PAYMENT-SIGNATURE. The current server uses the OKX facilitator. A successful response includes PAYMENT-RESPONSE. Payment buys analysis only; it does not fund a demand or purchase service execution.
